radiance-codec macOS CLI third-party notices
================================================

This package bundles third-party dynamic libraries so the CLI can run without
requiring Homebrew, pixi, Python modules, or system-wide codec installs.

Bundled components:

- OpenEXR
- Imath
- zstd
- libdeflate
- openjph
- LLVM OpenMP runtime (libomp)
- LLVM libc++
