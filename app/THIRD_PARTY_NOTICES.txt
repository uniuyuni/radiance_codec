radiance-codec macOS CLI third-party notices
================================================

This package bundles third-party dynamic libraries so the CLI can run without
requiring Homebrew, pixi, Python modules, or system-wide codec installs.

The radiance_codec library and CLI code are distributed under the BSD 3-Clause
License. See LICENSE in this package.

Redistribution note
-------------------

When rebuilding the package with different dependency versions, refresh this
file from the exact packages being bundled. The package intentionally bundles
only runtime dynamic libraries and the notices needed to identify their
licenses and sources.
